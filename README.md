# SmileCare Dental

A responsive dental-clinic website demo built with React, Vite, React Router, Tailwind CSS, and Lucide icons.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; run the configured Oxlint checks with `npm run lint`.

## Pages

- Home: clinic introduction, featured services, care team, testimonials, and appointment calls to action
- About: clinic story, values, and approach to care
- Services: eight dental services
- Our Doctors: dentist profiles and appointment requests
- Contact: clinic details, hours, map-style illustration, and a validated demo contact form

Appointment and contact forms are frontend-only demos. They do not send or store information, and appointment requests are not confirmed bookings. Clinic details and testimonials are illustrative. Photography and Google Fonts load from their external providers.
